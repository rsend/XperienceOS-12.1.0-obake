Android 8 dependency setup

Run from the checked-out SOURCE_RELEASE contents as a regular sudo-capable
user on Ubuntu 20.04 amd64:

    bash ./install_deps_android8.sh

This is the xpe711 setup model: the host installer installs Ubuntu packages,
then calls install_prebuilts.sh. That script fetches immutable Git commits
and copies only prebuilt-filelists/*.txt. File SHA-256 checksums, symlink
targets, and executable permissions are checked before each project is
installed. Existing conflicting directories are refused. A repeated run
verifies an installation with matching revision and inventory markers.

The reduced dependency set contains 44,133 inventory entries from 18 pinned
projects. Unused platform/compiler projects and test-module metadata have been
removed following source reduction. Installed hashes, links, and executable
modes pass verification. Required image compile commands remain unchanged.
Selected regular-file payload totals approximately 3.89 GiB; allocated size
varies. Fetching a pinned Git commit may download a larger object pack than
the inventory copied into the checkout.

Only two local prebuilt overrides exist: sdk/tools/jack-admin and
sdk/tools/jack-tls-legacy.security. They preserve the checkout-local Jack
state/ports and JDK 8 TLS compatibility repairs. Private Jack certificates,
keys, existing server installations, caches, and build outputs are excluded.

Ubuntu host packages are selected from Ubuntu 20.04's configured repositories.
Historical Android build inputs are separately pinned by commit, file list,
and checksum. This Oreo workflow retains Go for Soong and pinned Bison 2.7
and Flex 2.5.39; it does not copy xpe711's source-built Bison/no-Go choices.
The installer does not edit shell startup files, select global Java
alternatives, start Jack, fetch Android source, or run image builds.

Verification:

    bash ./install_deps_android8.sh --verify

For a host whose packages are already installed:

    bash ./install_deps_android8.sh --prebuilts-only
